# DANTE — Збирач програм на основі безкоштовних ШІ

**Dynamic Autonomous Neural Tool for Engineering.** Данте пише, перевіряє й збирає програми силами безкоштовних моделей ШІ та ресурсів звичайного ПК під Windows. Мета — «панацея бідних і надія ентузіастів та винахідників».

> ⚠️ Експериментальна версія: проєкт молодий і активно розвивається.

## Що вже вміє
- **Пише код за задачею** і доводить його до проходження тестів; кожна зміна — з можливістю відкотити.
- **Архітектор:** розбиває велику справу на кроки (план → погодження → виконання).
- **Хаб моделей:** Gemini, Groq, OpenRouter, NVIDIA, локальні моделі Ollama та інші; зручна форма додавання нових; **платні моделі — лише з подвійним підтвердженням суми**.
- **Вчиться на помилках:** пам'ять уроків, нічне навчання, коли ПК простоює.
- **Читач (Зір):** забирає код і цілі розмови з веб-чатів ШІ, розпізнає мову коду.
- **Мурашник:** «Мураха» на Rust — робочий вузол для інших ПК; координатор, автопошук у локальній мережі.
- **Пульт і сторож:** завдання через теку, паралельна робота, захист від перегріву, самоперезапуск.
- Код із **двомовними коментарями** (англійська / українська).

## Вимоги
Windows 10/11, Python 3.13 (лише стандартна бібліотека), для Мурахи — Rust. Безкоштовні ключі моделей вводяться у формі «+ Моделі».

## Запуск
```
python -m dante gui        # вікно Данте
python -m dante selftest   # самоперевірка
```
