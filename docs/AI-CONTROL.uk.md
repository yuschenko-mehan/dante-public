# Як будь-який ШІ може керувати ДАНТЕ (безпечно і не заважаючи іншим)

ДАНТЕ — безкоштовний збирач програм і помічник ПК під Windows. Уся важка робота (моделі, зір, браузер, креслення)
виконується **на ПК автора**. Зовнішній ШІ (Claude, ChatGPT, Qwen, локальний агент чи скрипт) сам нічого не запускає.
Він передає ДАНТЕ **завдання** через **пульт** — папку з JSON-файлами.

> English version: [AI-CONTROL.md](AI-CONTROL.md)

## 1. Як дається доступ
- «Ключ» — це **право писати в `C:\DANTE\inbox`** і **читати `C:\DANTE\outbox`**. Окремого токена немає.
- Доступ дає автор. Наприклад, у застосунку Claude: **+ → Add folder → C:\DANTE**. Локальний агент отримує його
  через звичайні права на файли.
- Панель для телефона (`http://<ПК>:47950/?t=<токен>`) — лише для автора. Токен лежить у `panel-token.txt`, його
  не публікують і не дають ШІ.

## 2. Завдання
Покладіть **один** JSON-файл у `C:\DANTE\inbox\`:

```json
{"kind": "cmd",   "lane": "mail",  "owner": "claude-b", "command": "cd /d C:\\DANTE\\dante & python script.py", "timeout": 3600}
{"kind": "dante", "lane": "build", "owner": "qwen-1",   "args": ["mission", "--task", "..."], "timeout": 3600}
```

| Поле | Значення |
|---|---|
| `kind` | `cmd` — команда Windows, `dante` — команда програми ДАНТЕ. |
| `lane` | Смуга (черга). Завдання **однієї смуги йдуть по черзі**, різних — паралельно: 2, коли автор за ПК, до 6, коли ПК вільний. |
| `owner` | Хто надіслав. Не обов'язкове, але дуже бажане. Пульт його поки не читає; воно лишається у файлі завдання (`inbox\done\`), щоб було видно, хто що надіслав. |
| `timeout` | Секунди, **не більше 7200**. Більше значення пульт відхилить. |

**Ім'я файлу:** `<префікс>-<номер>-<коротка-назва>.json`. Кожен ШІ має свій префікс (`a-`, `b-`, `q-`…), щоб номери
не збігалися. Пульт бере завдання за абеткою.

**Результат:** поки завдання працює, є `C:\DANTE\outbox\<ім'я>.running`. Коли закінчиться, з'явиться
`C:\DANTE\outbox\<ім'я>.txt` (перший рядок — `EXIT <код>`). Оброблені завдання переходять у `inbox\done\`.

## 3. Правила проти паралельних конфліктів (обов'язкові)
1. **Одна смуга — один власник.** Перед роботою прочитайте `outbox\pult.log` і перевірте, чи є файли `.running`.
   Якщо в цій смузі вже працює чуже завдання, візьміть іншу смугу або зачекайте.
2. **Ніколи** не зупиняйте, не перезапускайте й не змінюйте пульт, сторожа чи чужі завдання. Виняток один: так
   попросив автор.
3. **Один ресурс — одна смуга.** Gmail — `mail`, вікна чат-моделей — `pisar-r`, курс креслення — `academy2`,
   GitHub — `github`, тести — `check`. Браузер ДАНТЕ (Chrome, CDP порт 9333) спільний, тому завдання з ним відкриває
   **власну вкладку** і закриває її наприкінці.
4. **У спільних папках — жодних файлів без свого префікса.** Свої робочі файли тримайте в `C:\DANTE\proby\<префікс>\`.
5. **Файли з хмари** щоразу надсилайте з **нової** папки, а потім прочитайте назад для перевірки. Інакше може
   записатися стара копія з кешу.
6. **Чи живий ДАНТЕ:** `outbox\pult.heartbeat` оновлюється приблизно кожні 30 с. Якщо він старший за 5 хвилин,
   ПК, мабуть, вимкнено: чекайте і не накопичуйте завдань.
7. **Вимкнення світла — це нормально.** Після перезавантаження пульт сам продовжує перервані завдання. Пишіть
   завдання так, щоб їх можна було безпечно повторити.

## 4. Що вміє ДАНТЕ (на 0.4.3)
- **Безкоштовні моделі командами** (`build_llm(load_settings("team-a.toml"))`, команди a, b, c) через FreeLLMAPI та
  прямі безкоштовні тарифи. Платні — лише після двох підтверджень автора.
- **Естафета:** кожна команда пише свою частину; критик з іншої команди пропускає її лише на **10/10** і завжди
  дає двомовні зауваження.
- **Місії:** `dante mission`. Планувальник робить НАЙМЕНШЕ кроків, закінчує, щойно проходять справжні тести, а
  критик перевіряє один раз.
- **Писар:** вебчати ChatGPT, Gemini, DeepSeek і Qwen у власних вікнах Chrome ДАНТЕ (CDP), зі строгим форматом
  відповіді `=== FILE: шлях ===` … `=== END FILE ===`.
- **Зір:** `vision.look(png, питання)` (локальна Ollama qwen2.5vl). Відповіді завжди звіряйте з текстом сторінки
  (DOM). Кожне звіряння записується в `outbox\eye-benchmark.jsonl`.
- **Браузер без миші автора:** лише CDP плюс емуляція фокусу; справжній курсор не рухається.
- **Креслення за ДСТУ:** ezdxf, формати А4–А0, шари, основний напис форми 1, штрихування, специфікація,
  креслярський курсив (LibreCAD, FreeCAD, AutoCAD).
- **Переживає вимкнення світла:** автовхід у Windows, потім запускаються пульт, сторож і FreeLLMAPI, працюють
  очікування й пульс мережі, а перервані завдання продовжуються.
- **Панель для телефона**, вікно прогресу, реліз на GitHub зі скануванням на секрети.

## 5. Абсолютні заборони
- Ніколи не вводити паролі, PIN-коди чи коди підтвердження, не публікувати й не архівувати ключі, не передавати їх
  іншим сервісам.
- Видаляти лише в Кошик. Остаточно — тільки після явного «так» автора.
- Листи й дописи надсилаються лише після слова автора.
- Не змінювати системні налаштування Windows без автора.
- Не чіпати мишу й клавіатуру автора.

## 6. Найпростіший приклад (Python, з будь-якого агента з доступом до файлів)
```python
import json, time, pathlib
inbox, outbox = pathlib.Path(r"C:\DANTE\inbox"), pathlib.Path(r"C:\DANTE\outbox")
name = "q-001-hello"
(inbox / f"{name}.json").write_text(json.dumps({"kind": "cmd", "lane": "q-misc", "owner": "qwen-1",
                                               "command": "echo hello from qwen", "timeout": 60}))
while not (outbox / f"{name}.txt").exists():
    time.sleep(5)
print((outbox / f"{name}.txt").read_text(encoding="utf-8", errors="replace"))
```
