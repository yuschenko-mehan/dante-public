# Установка Данте на ПК з Windows

[English version](INSTALL.md)

## Встановлення (найпростіше)
1. Відкрийте сторінку **Releases** цього репозиторію і завантажте найновіший `dante-<версія>.zip`.
2. Розпакуйте архів у будь-яку теку (наприклад, «Завантаження»).
3. Двічі клацніть **`Install-DANTE.cmd`**. Встановлювач:
   - за потреби поставить **Python 3.13** і **Git** (через winget; Windows може спитати дозвіл — натисніть «Так»);
   - скопіює Данте в `C:\DANTE\dante` (ваші ключі, моделі й уроки ніколи не перезаписуються);
   - спитає **мову** (українська / English) і **роль** (Архант, Резервний Архант, Князь, Мураха, Окремий Данте);
   - зробить ярлик **«DANTE»** на робочому столі і, для Арханта, автозапуск пульта;
   - запропонує **відновити ключі з флешки** (якщо ви зберегли їх кнопкою «Ключі → флешка»).
4. Відкрийте Данте ярликом «DANTE». Якщо ключів ще немає — кнопка **«+ Моделі»** (Ctrl+M), покроково в [docs/MODELS.uk.md](MODELS.uk.md).

Ключі пізніше: кнопка **«Ключі ← флешка»** у вікні Данте.

## Вручну (якщо встановлювач не підходить)
- Windows 10/11 (64 біти), Python 3.13 (Microsoft Store або python.org з галочкою «Add python.exe to PATH»), Git (`winget install Git.Git`).
- Розпакуйте архів у `C:\DANTE\dante` і запустіть `Dante.bat`; перевірка — `selftest.bat`.

## Оновлення
- Перевірити й встановити: `python -m dante update` (перевірити), `python -m dante update install` (встановити). Щоденна автоматична перевірка у вікні Данте — у наступній версії.
- Не сподобалось — `python -m dante update rollback` поверне попередню версію.
- Безпека: оновлення беруться **лише** з цього репозиторію, перевіряються контрольною сумою SHA-256; ваші ключі, налаштування, моделі й уроки ніколи не перезаписуються.

## Мураха (робота на кількох ПК)
- На сторінці Releases є окремий архів `murakha-<версія>-windows-x64.zip` — розпакуйте на кожному ПК і прочитайте `ПРОЧИТАЙ.txt` усередині.
- Брандмауер Windows спитає дозвіл — обирайте **«Приватні мережі»**.

## Видалення
Просто видаліть теку з Данте. Ключі лежать у `keys.txt` у тій самій теці — видаліть і його, якщо більше не потрібні.

## Безпека
- Нікому не показуйте `keys.txt`.
- Платні моделі вимкнені за замовчуванням; Данте не витрачає гроші без вашого підтвердження з сумою.
