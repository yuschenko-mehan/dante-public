# Як додати нову модель ШІ до Данте

[English version](MODELS.md)

Данте вміє працювати з будь-яким сервісом, що «розмовляє» мовою OpenAI (так звані OpenAI-сумісні сервіси), а також з моделями, які працюють прямо на вашому ПК (Ollama, LM Studio). Додати модель можна мишкою, без програмування.

## Спосіб 1. Через вікно «+ Моделі» (рекомендовано)

1. Запустіть Данте (`Dante.bat`) і натисніть кнопку **«+ Моделі»** або **Ctrl+M**.
2. Натисніть **«Нова»**.
3. У полі **«Сервіс»** оберіть готовий варіант. Адресу й назву ключа Данте підставить сам:

   | Сервіс | Ключ | Де взяти ключ |
   |---|---|---|
   | Ollama — модель на цьому ПК | не потрібен | https://ollama.com/library |
   | LM Studio — модель на цьому ПК | не потрібен | https://lmstudio.ai |
   | Google Gemini | `GEMINI_API_KEY` | https://aistudio.google.com/apikey |
   | Groq | `GROQ_API_KEY` | https://console.groq.com/keys |
   | OpenRouter | `OPENROUTER_API_KEY` | https://openrouter.ai/keys |
   | NVIDIA build | `NVIDIA_API_KEY` | https://build.nvidia.com |
   | Cerebras | `CEREBRAS_API_KEY` | https://cloud.cerebras.ai |
   | SambaNova | `SAMBANOVA_API_KEY` | https://cloud.sambanova.ai |
   | Mistral | `MISTRAL_API_KEY` | https://console.mistral.ai/api-keys |
   | Cohere | `COHERE_API_KEY` | https://dashboard.cohere.com/api-keys |
   | Hugging Face | `HF_TOKEN` | https://huggingface.co/settings/tokens |
   | Свій сервіс (OpenAI-сумісний) | свій | адресу вписуєте самі |

4. Натисніть **«Де взяти ключ»** — відкриється сторінка сервісу. Зареєструйтесь (це робите **ви самі**), створіть ключ і скопіюйте його.
5. Вставте ключ у поле **«Ключ»**. Він зберігається лише у файлі `keys.txt` на вашому ПК — нікуди не надсилається й на GitHub не потрапляє.
6. Натисніть **«Отримати список»** — Данте спитає сервіс, які моделі доступні (це безкоштовно). Оберіть модель зі списку.
7. **«Назва в Данте»** заповниться сама (наприклад `cerebras-llama-3-3-70b`); можна змінити.
8. Натисніть **«Перевірити»** — Данте надішле моделі одне коротке слово й покаже, чи відповіла вона і за скільки секунд.
9. Натисніть **«Зберегти»**. Готово — модель з'явиться у списку зі зірочкою ★ і Данте почне її використовувати.

Позначки у списку: ✓ ключ є · - ключа немає · $ платна · ★ ваша.

## Платні моделі — захист від витрат

- Для сервісу «Свій сервіс» позначка **«Платна модель»** стоїть одразу — на всяк випадок.
- Для платної моделі треба вказати ціну (долари за 1 мільйон токенів на вхід і на вихід).
- Кнопка «Перевірити» платну модель **не викликає** — навіть одна перевірка коштувала б грошей.
- Без вашого подвійного підтвердження з сумою Данте не витрачає гроші. За замовчуванням працюють лише безкоштовні моделі.

## Спосіб 2. Модель на власному ПК (без інтернету)

1. Встановіть **Ollama** (https://ollama.com) або **LM Studio** (https://lmstudio.ai).
2. Завантажте модель, наприклад у командному рядку: `ollama pull qwen2.5-coder:7b`.
3. У вікні «+ Моделі» оберіть сервіс «Ollama — модель на цьому ПК», натисніть «Отримати список», виберіть модель, «Перевірити», «Зберегти».

Порада: команда `python -m dante setup` покаже, які локальні моделі підходять під вашу відеокарту й пам'ять.

## Спосіб 3. Вручну, файлом (для досвідчених)

Ваші моделі лежать у файлі `models.json` поруч із папкою `dante`:

```json
{"models": [
  {"name": "cerebras-llama", "base_url": "https://api.cerebras.ai/v1", "model": "llama-3.3-70b",
   "key_env": "CEREBRAS_API_KEY", "needs_key": true, "paid": false, "price_in": 0, "price_out": 0,
   "note": "швидка"}
]}
```

А ключ — у `keys.txt`, окремим рядком: `CEREBRAS_API_KEY=ваш_ключ`

Правила: назва — малі латинські літери, цифри й дефіс (2–31 символ); адреса — `https://…` або `http://localhost…`/`http://127.0.0.1…`.

## Перевірити всі моделі разом

- Двічі клацніть `keys.bat` — він покаже, які ключі працюють і які моделі доступні.
- Або в командному рядку: `python -m dante models` (ключі й списки) та `python -m dante ping` (швидкість відповіді кожної моделі).

## Безпека

- **Нікому не показуйте `keys.txt`** і не викладайте його в інтернет. Данте сам не допускає його на GitHub (перевірка на секрети перед кожною публікацією).
- Якщо ключ випадково «засвітився» — видаліть його на сайті сервісу і створіть новий.
